# Перенос агента на VPS (155.212.144.185)

Боевой бот — серверный `@norwik_helper_bot`; локальный остаётся для тестов (решение
08.10.2026). Переезжает состояние агента: база `users.db` (модель прайсов и задач,
справочники, журналы, очередь команд и связки с командами 1С) и файлы прайсов
`data/prices/`.

Зачем: с VPS до 1С доходят 20 из 20 TCP-соединений, с рабочей станции через VPN —
4–6 из 20.

## Перед окном переключения

1. В `/opt/norwik-helper/.env` на сервере дописать `ONEC_BASE_URL` и `ONEC_TOKEN` —
   те же, что в локальном `.env`. Скрипт выкладки без них не стартует.
2. Убедиться, что `master` содержит нужный коммит (`git log origin/master -1`).

## Окно переключения

1. **Остановить локального бота** (Ctrl+C в его консоли). Агент должен быть один: две
   копии, опрашивающие очередь 1С, выполнят одну команду дважды.
2. Снимок на рабочей станции:
   ```
   .venv\Scripts\python -m tools.migrate_to_vps.snapshot
   ```
   Печатает путь к `data\exports\migration\agent-state-<время>.tar.gz`.
3. Отправить архив и скрипты на сервер:
   ```
   scp -i %USERPROFILE%\.ssh\id_ed25519_prodbot data\exports\migration\agent-state-<время>.tar.gz root@155.212.144.185:/root/
   scp -i %USERPROFILE%\.ssh\id_ed25519_prodbot tools\migrate_to_vps\deploy.sh tools\migrate_to_vps\rollback.sh root@155.212.144.185:/root/
   ```
4. Выкладка на сервере:
   ```
   bash /root/deploy.sh /root/agent-state-<время>.tar.gz
   ```
   В конце скрипт печатает строки журнала старта, число файлов прайсов и команду отката.

## Что проверить после

- В журнале есть «Цикл модели запущен» и «Run polling», нет `Traceback`.
- Файлов прайсов после старта столько же, сколько в снимке (скрипт сравнивает сам).
- Форма 1С: список прайсов и задач на месте, команда «Обновить» доходит за секунды.
- Telegram: `@norwik_helper_bot` отвечает админу на `/prices`.
- **Подписчики сводки и рассылки фото должны хотя бы раз написать `@norwik_helper_bot`**
  — первым Telegram писать не даёт, а это другой бот, не тот, с которым они общались.

## Локальный бот после переноса

Он остаётся для тестов, но **с ONEC_* в `.env` он снова начнёт забирать команды 1С** у
боевого. Перед следующим запуском уберите из локального `.env` `ONEC_BASE_URL` и
`ONEC_TOKEN` (или направьте их на тестовую базу 1С).

## Откат

```
bash /root/rollback.sh /opt/norwik-helper-backup/<время>
```
Возвращает том данных, `.env` и коммит, какими они были до выкладки. Всё, что новый бот
сделал после выкладки, при откате теряется.
